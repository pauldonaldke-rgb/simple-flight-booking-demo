# Simple Flight Booking Demo

A compact, single-page flight search and booking-flow example using illustrative
flight data.

## Run

Open `index.html` in a modern browser. No packages or build step are needed.

## Local demo data

- Search history is stored in this browser using IndexedDB.
- Simulated bookings are stored in this browser's local storage.
- Data stays on this device. It is not sent to a server or shared with other
  users or devices.

## Important

This is a demo, not an airline booking service. Flight prices and schedules are
sample data. The page does not connect to live inventory, accept payments,
create reservations, or issue tickets. Do not enter real payment or passport
details.

The sample uses Kenya Airways flight labels only to illustrate the interface;
this repository is not affiliated with or endorsed by Kenya Airways.
